# Reproducibility Guide

This document describes how to reproduce the analysis in this repository for the thesis *Shifting Forms of Racial Disparity in Policing and Prosecution: Evidence from Orange County’s Criminal Legal System*.

The repository is organized around two notebooks:

1. `notebooks/01_ripa_cleaning.ipynb`
2. `notebooks/02_analysis.ipynb`

The first notebook downloads and cleans Orange County RIPA stop data for 2022–2024. The second notebook loads the cleaned policing data, the cleaned prosecution data, and 2020 Census population denominators, then reproduces the descriptive analysis, figures, and LaTeX tables used in the thesis.

`adjustText` is used to improve label placement in the agency-level hit-rate figure. The plotting code includes a fallback if it is unavailable, but installing it is recommended for full replication of the published figure appearance.

## Data Inputs

The analysis relies on three data sources.

### 1. Policing Data: Orange County RIPA Stop Data, 2022–2024

The notebook `notebooks/01_ripa_cleaning.ipynb` downloads Orange County stop data directly from the California DOJ/OpenJustice portal using public ZIP files for 2022, 2023, and 2024. It then harmonizes the 2024 schema to match prior years and exports a cleaned file to:

```text
data/processed/cleaned_orange_ripa_2022_2024.csv
```

This file is generated by the notebook and does not need to be downloaded manually in advance.

### 2. Prosecution Data: Cleaned Orange County RJA File, 2021–2023

The repository includes the processed prosecution input used for the analysis:

```text
data/processed/cleaned_orange_aclu_2021_2023.csv
```

This file is the cleaned Orange County prosecution dataset used in the thesis.

### 3. Population Denominators: 2020 U.S. Census PL Table P2

Population data are retrieved at runtime from the U.S. Census API and used to compute per-capita policing exposure measures.

## Execution Order

Run the notebooks in the following order.

### Step 1: Run `notebooks/01_ripa_cleaning.ipynb`

This notebook:

- downloads Orange County RIPA stop data for 2022 and 2023 from DOJ ZIP files
- downloads Orange County RIPA stop data for 2024 from a separate DOJ ZIP file
- harmonizes the 2024 format to match the earlier years
- constructs derived analysis variables
- concatenates all years into one cleaned dataset
- saves the result to `data/processed/cleaned_orange_ripa_2022_2024.csv`

### Step 2: Run `notebooks/02_analysis.ipynb`

This notebook:

- loads the cleaned policing file produced in Step 1
- loads the cleaned prosecution dataset
- queries 2020 Census PL Table P2 data via the Census API
- computes policing stop, search, and hit-rate summaries
- computes policing results by reason for contact
- computes agency-level White–Black hit-rate comparisons
- computes sensitivity analyses for alternative discretionary-search definitions
- computes prosecution enhancement analyses
- computes wobbler felony-filing analyses
- generates display tables and figure objects corresponding to the thesis outputs

## Analytic Details Relevant for Replication

### Race Harmonization

Both policing and prosecution data are harmonized into a common five-category race variable:

- `Black/African American`
- `Hispanic/Latino`
- `White`
- `Asian`
- `Other`

This standardization is implemented in `src/analysis_utils.py` and is used throughout downstream summaries, tables, and visualizations.

### Policing Sample Restrictions

The policing analysis is restricted to discretionary stop contexts:

- `Moving violation`
- `Equipment violation`
- `Non-moving violation`
- `Suspect criminal activity`

The main policing analysis further restricts to `person_number == 1` for each stop, while a separate sensitivity analysis considers all persons involved in multiperson stops.

### Search Definitions

The baseline policing analysis defines discretionary searches using `search_type == "Discretionary only"`.

A sensitivity analysis also includes a broader search classification that treats `Mixed` and `No search basis` searches as discretionary.

### Enhancement Analysis

The prosecution analysis treats the raw file as charge-level data, then builds case-level measures for enhancement analyses. Cases are classified by primary statute level and primary charge category using a severity-based hierarchy implemented in `src/analysis_utils.py`.

### Wobbler Analysis

The wobbler analysis reports felony filing rates for charges eligible to be filed either as misdemeanors or felonies. In the by-category view, the analysis excludes:

- the `Other` category
- categories with fewer than 500 total wobblers
- categories with overall felony filing rates below 10%

## Internet Requirements

Internet access is required for full reproduction because the workflow depends on external data access:

- `01_ripa_cleaning.ipynb` downloads public RIPA ZIP files from the California DOJ/OpenJustice portal
- `02_analysis.ipynb` queries the U.S. Census API for PL Table P2 population denominators
- in the current notebook version, `02_analysis.ipynb` also reads the prosecution CSV from the repository’s raw GitHub URL

A replication run without internet access will fail unless those dependencies are replaced with local files.
